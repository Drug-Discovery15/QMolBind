# QuMolBind

Hybrid quantum-classical RL (PPO with a classical-MLP or VQC actor) for ligand torsion search in a rigid protein pocket.
Work in progress; no results are reported until generated by code in this repo (see `results/`, `REPORT.md`).

Setup (Windows, no conda): `python -m venv .venv`, then `.venv\Scripts\python scripts/tasks.py env`.
Tasks: `python scripts/tasks.py {env|data|test|smoke|baselines|train-q|experiments|report}` (or `make <task>` where make exists).
Design decisions and deviations: [DECISIONS.md](DECISIONS.md).
